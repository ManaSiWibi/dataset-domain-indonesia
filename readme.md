# How to refresh the data
Steps to obtain or update each dataset in this repository.

## Tranco
Download the daily list from https://tranco-list.eu/latest_list, take the domain column, and keep only the ones ending in `.id`. The List ID changes daily — replace `46ZYX` with the latest ID.
```
$ curl -O -J -L https://tranco-list.eu/download/46ZYX/full
$ tr -d '\r' < tranco_46ZYX_full.csv | awk -F',' '{print $2}' | grep '\.id$' > Tranco/domains.txt
```
For the top-1M subset (domains ranked ≤ 1,000,000):
```
$ tr -d '\r' < tranco_46ZYX_full.csv | awk -F',' '$1<=1000000 && $2 ~ /\.id$/' | awk -F',' '{print $2}' | sort -u > Tranco/top-1m/domain.txt
```

## ipsniper
Download the zone file per TLD from the public ipsniper archive, then decompress.
```
$ mkdir -p ipsniper
$ for tld in ac biz co desa go kop mil my net or ponpes sch web xn--9tfky; do
>   curl -sL -o "ipsniper/$tld.id.txt.gz" \
>     "https://ipsniper.info/archive/latest/zonefiles/public/$tld.id.txt.gz"
> done
$ curl -sL -o ipsniper/id.txt.gz \
>   "https://ipsniper.info/archive/latest/zonefiles/public/id.txt.gz"
$ for f in ipsniper/*.gz; do gunzip -k "$f"; done
```
`ipsniper/<tld>.id.txt` is zone-file format: `domain\tIN\t<record>\t<value>` (A/AAAA/NS/CNAME/MX).

## Domains Project
The source does not offer a per-TLD download; the `.id` data is a single `.xz` shard on the GitHub mirror.
```
$ curl -sL -o "Domains Project/domain2multi-id00.txt.xz" \
>   "https://media.githubusercontent.com/media/tb0hdan/domains/master/data/indonesia/domain2multi-id00.txt.xz"
$ xz -dk "Domains Project/domain2multi-id00.txt.xz"
```
For the full TLD list or other countries: https://github.com/tb0hdan/domains (Git LFS mirror + `./unpack.sh`). The raw data at `https://dataset.domainsproject.org/` requires authentication.

## Common Crawl
Data comes from the Host Index v2 (Parquet) dataset on HuggingFace. The query runs in DuckDB reading Parquet over HTTP range requests — no need to download the whole dataset (~9 GB per crawl).
```
$ pip install duckdb
$ python3 - <<'EOF'
import duckdb
con = duckdb.connect()
con.execute("INSTALL httpfs; LOAD httpfs;")
base = "https://huggingface.co/datasets/commoncrawl/host-index-testing-v2/resolve/main/data/crawl=CC-MAIN-2025-18"
files = [f"{base}/CC-MAIN-2025-18.part-{i:05d}.parquet" for i in range(30)]
con.execute(f"""
  COPY (
    SELECT DISTINCT url_host_registered_domain
    FROM read_parquet({files!r})
    WHERE url_host_tld = 'id'
    ORDER BY url_host_registered_domain
  ) TO 'commoncrawl/domain2multi-id.txt' (HEADER FALSE)
""")
EOF
```
Replace `CC-MAIN-2025-18` with the newest crawl ID from https://commoncrawl.org/the-data/.

## Union (latest.txt / latest.csv)
After the four datasets above are updated, run `combine.py` to produce the normalized, deduplicated union, then `audit.py` to regenerate and verify the tables in this file:
```
$ python3 combine.py
$ python3 audit.py
```
`combine.py` reads every source, writes `latest.txt` (sorted union) and `latest.csv` (with source trace), and prints the counts to stderr. No external dependencies (standard Python 3 only).

## Verify the counts
`python3 audit.py` prints every table above (per source, per suffix, union) and validates `latest.txt`: line count equals the union, no duplicates, lowercase, no `www.` prefixes, no trailing dots, and the sort order is `(-source_count, domain)`. It exits non-zero if any check fails, so it can be used as a pre-commit sanity check.

Suffix grouping (`suffix()` / `registered_domain()` in `combine.py`) is driven by `KNOWN_2LD`, which is derived from the Public Suffix List's `// id` section. Re-check it whenever a source is refreshed:
```
$ curl -sL https://publicsuffix.org/list/public_suffix_list.dat \
    | sed -n '/^\/\/ id :/,/^\/\/ [a-z][a-z] :/p' | grep -v '^//'
```
Any label in that output which is missing from `KNOWN_2LD` would be miscounted as a plain `.id` domain.

## Update cycle
Updates follow each source's release cycle:
- **Tranco** — daily (https://tranco-list.eu/latest_list)
- **ipsniper** — monthly, usually at the start of the month (https://ipsniper.info/)
- **Domains Project** — unscheduled, every few months
- **Common Crawl** — monthly (https://commoncrawl.org/the-data/)
